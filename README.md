# Study Planner

A Java application for planning university studies and tracking completed credits.

## Purpose

Students often need a simple way to keep track of completed courses and earned credits. This project is being developed as a study planning tool that allows users to manage courses and monitor academic progress.

## Current Features

- Java console application
- Course com.studyplanner.model.model implementation
- Basic object-oriented design

## Planned Features

- Add courses
- Display all courses
- Mark courses as completed
- Calculate completed credits
- Store data between sessions
- Database integration
